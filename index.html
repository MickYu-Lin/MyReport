02-附錄｜技術關聯：其實有兩條不同路徑

同樣是「AI 幫你買東西」，入口在哪裡，決定了誰掌握使用者關係。

路徑 A｜Albertsons / Safeway 自家 AI

Ask AI / AI Shopping Assistant：使用者先進零售商自己的 App / Website
User→ Safeway App / Web→ AI Agent / Model
User Profile / Loyalty 商品資料 價格 / 庫存 / 優惠
  • 採用 Google Cloud 的 Conversational Commerce agent / Vertex AI，並使用 Gemini。Conversational Commerce 是一套「用 AI 做對話式購物」的 agent / solution
  • 企業後端先從會員、購買紀錄與商品 DB 取出「這次需要的 context」，再交給模型推理。
  • User Profile 的主資料仍在 Albertsons / Safeway 系統中，不是把整個會員檔永久存成模型自己的記憶。

路徑 B｜ChatGPT 裡直接 @Safeway

Safeway Plugin：使用者先進 ChatGPT，零售商能力反過來被接進 AI 平台
User→ ChatGPT→ @Safeway Plugin
Safeway Account→ Product / Price / Coupon→ Cart / Checkout
  • 使用者先連結 / 登入 Safeway 帳號，ChatGPT 取得被授權的外部工具能力，而不是取得帳號密碼。
  • ChatGPT 負責理解自然語言與規劃需求；Safeway 後端提供會員、商品、價格、優惠、購物車等即時資料與 action。
  • 最後交易仍由 Safeway 的 commerce backend / checkout 完成。
最重要的差異：
路徑 A 是「AI 被嵌入零售商平台」；路徑 B 則是「零售商被嵌入 AI 平台」。
這也就是為什麼 ChatGPT 可能逐漸取得最有價值的 Decision Layer（決策層）。
資料保存：
ChatGPT 一般使用者的 Memory / history 是「產品層功能」；企業 API / plugin request 則是另一套資料治理。
「不拿去訓練」≠「絕對零保存」，實際保留政策取決於產品、合約與企業設定。

P5-附錄 B｜Google 怎麼爬網站？又怎麼不讓它爬？

Googlebot 本質上就是一個自動 HTTP Client：發現 URL、抓 HTML、必要時 Render，再決定是否建立索引

① 發現 URL既有索引、其他網站連結、Sitemap 等
② Crawl QueueURL 排入抓取佇列
③ robots.txt先確認 Googlebot 是否允許抓取
④ HTTP FetchGET URL，取得 HTML / HTTP headers
⑤ Parse / Render解析 HTML、連結；必要時執行 JavaScript
⑥ Index理解內容、canonical、訊號後決定是否納入索引

不想讓它「爬」

robots.txt 是最標準的 crawl control。Googlebot 在抓取前會讀取它。

User-agent: Googlebot Disallow: /private/

注意：擋 crawl ≠ 保證 URL 不會出現在搜尋結果。

可以爬，但不要「收錄」

在可被 Google 抓到的頁面使用 noindex：

<meta name="robots" content="noindex">

或用 HTTP X-Robots-Tag: noindex。若 robots.txt 已擋住頁面，Google可能看不到 noindex。

內容真的不能公開

使用 登入、ACL、密碼、授權 等真正的 access control；必要時可在 CDN / WAF 驗證並封鎖 crawler。

Internet → CDN / WAF → Auth / ACL → Web Server

robots.txt 是「規則」，不是資安邊界；不應拿來保護機密內容。

07｜AI 公司開始買書
Anthropic｜Project Panama

購買大量實體書 → 拆書脊 → 掃描 → 建立訓練資料

2026 年曝光的內部資料顯示，Anthropic 曾大量購買實體書，進行破壞式掃描，以建立可供模型使用的數位書庫。這與早期使用爭議性「shadow libraries」形成對比，也顯示 AI 訓練資料正逐步走向合法取得與資產化。

Washington Post, 2026/1/27；另見 Reuters, 2026/7/22
為什麼要買？

AI 的瓶頸正在從「算力」延伸到「高品質、合法、可持續的資料」

公開網路資料有雜訊、重複、權利風險；書籍、期刊、專業 DB、新聞 archive 則具有更高品質與更明確的權利邊界。

商業意義： 內容不再只是吸引人類眼球的媒體商品，也可能成為供 AI 消費的「B2B 資料原料」。
